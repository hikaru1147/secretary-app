# 自分専用の秘書アプリ

メモ・タスク・週次の振り返りを管理できる、シンプルな個人用秘書アプリです。
Node.js の標準モジュールのみで動作し、追加のインストールは不要です。

## 機能

- **ダッシュボード** … メモ件数・タスク件数・未完了タスク件数・最新の振り返りを表示
- **メモ** … タイトルと本文で記録／一覧表示／削除（作成日時つき）
- **タスク** … 追加／完了の切り替え／削除（作成日時・完了状態つき）
- **週次の振り返り** … 週ごとにコメントを記録（同じ週は上書き）／一覧表示／削除

データは `data.json` に自動保存され、アプリを閉じても消えません。

## 動作環境

- [Node.js](https://nodejs.org/)（標準モジュールのみ使用）

## 使い方

```bash
node server.js
```

起動後、ブラウザで <http://localhost:3000> を開きます。
終了するには、ターミナルで `Ctrl + C` を押します。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `server.js` | Node.js の HTTP サーバー（API と画面の配信） |
| `index.html` | 画面（ダッシュボード・メモ・タスク・振り返り） |
| `data.example.json` | データファイルの初期フォーマット例 |
| `data.json` | 実際のデータ保存先（自動生成／Git管理外） |

> `data.json` には個人的な内容が入るため、`.gitignore` で Git 管理から除外しています。
