# 自分専用の秘書アプリ

メモ・タスク・週次の振り返りを管理できる、シンプルな個人用秘書アプリです。
サーバー不要で動く**静的Webアプリ**で、データは**ブラウザ内（localStorage）に保存**されます。

## 機能

- **ダッシュボード** … メモ件数・タスク件数・未完了タスク件数・最新の振り返りを表示
- **メモ** … タイトルと本文で記録／一覧表示／削除（作成日時つき）
- **タスク** … 追加／完了の切り替え／削除（作成日時・完了状態つき）
- **週次の振り返り** … 週ごとにコメントを記録（同じ週は上書き）／一覧表示／削除

> データは、それを見ているブラウザ・端末の中（localStorage）に保存されます。
> アプリを閉じても消えませんが、別の端末や別のブラウザとは共有されません。

## デプロイ（Cloudflare Pages）

GitHub 連携で公開できます。Cloudflare Pages の設定は次の通りです。

| 項目 | 設定値 |
|---|---|
| フレームワークのプリセット | None（なし） |
| ビルドコマンド | （空欄） |
| ビルド出力ディレクトリ | `/`（ルート） |

`index.html` がそのまま配信され、`https://<プロジェクト名>.pages.dev` で公開されます。

## ローカルでの動作確認

`index.html` をブラウザで直接開くだけでも動きますが、付属の簡易サーバーでも確認できます。

```bash
node server.js
```

起動後、ブラウザで <http://localhost:3000> を開きます（終了は `Ctrl + C`）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・データ保存すべてを含む静的ファイル） |
| `server.js` | ローカル確認用の簡易サーバー（デプロイには不要） |
| `data.example.json` | 旧サーバー版のデータ形式の例（参考用） |
